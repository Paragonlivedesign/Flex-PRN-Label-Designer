Reset label defaults in the header restores 2×1 in, 203 DPI, 0.05" margins on all sides (header fields update), printable area off (full label), canvas workspace on, hides the yellow calibration overlay, clears imported ZPL back to designer ZPL, square label shell on canvas, and turns preview margin outline and label-edge overlay off; your objects stay. Appearance — optional rounded label corners on the canvas (cosmetic; does not change ZPL). Workspace margin (px) sets how much gray pad surrounds the label for dragging elements past the sticker edge (default 72; 24–720); designer-only.

Print calibration — use Settings → Calibration (or Calibrate in the corner to open that tab). Click Calibrate (corner FAB) to show the yellow box and enable calibration ZPL ticks. Sections cover Labelary margin/label-edge overlays, yellow box snap/match/apply, optional grid/ticks and ZPL tick marks, export/import, and reset guidance. Set printable area from yellow box sets label W×H, rulers, and ^PW/^LL to the yellow overlay. Use the pink Margin box (header checkbox + Set margins button) to set margins without changing label size. Export / Import calibration is label setup JSON only (no canvas objects). Export all settings on the Printer tab bundles printer, Flex API, and calibration in one file. Pick a tool and click to place; drag to move. With an object selected, drag the blue corner squares (bottom-right = grow; top-left on shapes = shrink/move corner).

Labelary preview — Show margin outline draws a light red dotted rectangle over the preview image for the printable area (inside margins). It is display-only and does not change ZPL.

Text: SE only — on-canvas size tracks ZPL ^AfN (font f = 0, A–H, P–V) height/width (dots). Barcode: SE only (2D = magnification; QR pattern uses Labelary-compatible encoding when online).

Rotate / flip — in Properties, use ↺/↻ for 90° steps and Flip H/V. Exported ZPL sets orientation N/R/I/B (0°/90°/180°/270° CW) on ^A (text) and ^BQ/^BC/… (barcodes). ^FW wraps lines/boxes. Images encode rotation and flip directly in the ^GFA bitmap so Labelary preview matches the canvas. Flip is preview-only for text and barcodes.

Snap, show grid, Grid from center (spacing through the printable center), Show center guides (light red crosshairs + snap targets), and grid spacing are under the canvas. Layers: the eye control hides an element on the canvas and in ZPL without removing it from the stack (select the row to edit or show again). Settings → Layout has the Flex header toggle and default merge tokens for new Text/Barcode tools.

Test data — turn on Test data next to Calibrate (bottom-right) to preview the label with sample strings instead of only live API merge values. Under Settings → Test data, use Long sample set or Short sample set to load presets, or type your own. While test mode is on, any non-empty test string overrides the API-loaded value for that merge token in the canvas and in substituted ZPL for preview and printer.

Resets (header only — same actions, no duplicate buttons here)

  • Reset canvas — designer ZPL (exits import), printable area off, workspace on, yellow overlay off, square label shell, selection cleared. Keeps label W×H, margins, objects, and Labelary margin/label-edge toggles.
  • Reset defaults — factory 2×1 in, default margins, printable off, workspace on, yellow off, designer ZPL, preview margin outline and label-edge overlays off. Objects stay (clamped to fit).

Calibration — align the canvas and margins with a physical label. Click Calibrate (corner FAB) to show the yellow box and enable calibration ZPL ticks for printing.

  1. Snap yellow to the green printable area (or match a Box / Labelary label edge), then drag on the canvas to match the real sticker trim.
  2. If the nominal label size is right but print is shifted on the die-cut → use the pink Margin box (header) to set margins only (same ^PW/^LL).
  3. If the header W×H / ^PW/^LL are wrong for the media → Set printable area from yellow box (changes rulers and ZPL size).

Passive overlays only help you see alignment; Apply as margins / Set printable area / Set margins (pink box) change real settings.

Labelary preview (bottom panel)

Show margin outline — passive dotted rectangle: where the printable area would fall if the bitmap matches nominal ^PW/^LL. Does not change ZPL.
Show label edge — blue outline showing the full label boundary (actual label size at correct aspect ratio). Not interactive — just a visual reference.

Yellow overlay (canvas)

Label dot coordinates from the top-left of the white label (0…W×H); with Canvas workspace on, the box can extend into the gray pad. Drag corners and edges on the canvas. Click Calibrate (corner FAB) to show it and enable ZPL ticks.

Label size — rulers and ZPL

Sets header W×H to the yellow box and remaps elements to the same physical dots. Turn the yellow overlay on first. Uses ^PW/^LL dot counts from the new size.

Optional: ZPL tick marks on print

Adds short ^GB tick segments along the bottom and left label edges (10-dot spacing, capped) for a physical calibration print. Affects generated ZPL only when this is on.

Save / share

JSON includes label size, DPI, margins, workspace flags, and yellow box — not canvas objects. Import runs clamp to printable on all objects if the area shrinks.

Pink margin box

A separate pink rectangle for adjusting margins only (ML/MT/MR/MB). Does not change label W×H. Show/hide and apply in the header, or use the controls below.

Resets

Use the header Reset canvas for view/import cleanup (keeps label size, margins, objects, and Labelary preview toggles). Use Reset defaults for factory label size and margins plus preview overlay toggles off. See Help for the full comparison.

Browsers cannot open raw TCP. Copy PowerShell send and run in PowerShell on a PC that can reach the printer (same site or VPN). Use Flex, or set a Relay URL (POST body = ZPL) on a server that can reach the printer. From a PC, check reachability with: Test-NetConnection <host> -Port <port> (PowerShell).
