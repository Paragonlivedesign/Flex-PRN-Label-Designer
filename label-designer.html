Choose defaults before you place new objects. The sample string only changes how the on-screen QR looks in the designer so you can judge size and crowding; exported ZPL for Flex mode still uses [barcode].

Label size is the physical media; margins define the printable area inside it (green dashed). Red tint is still on the label — turn on In margins to place there. Extra gray around the label on the canvas is workspace only. Only the label rectangle maps to ZPL.

Red tint = margin (won’t print as content unless you use tokens that print there). Reset label defaults in the header restores 2×1 in, 203 DPI, 0.05" margins, and turns off in-margins and the yellow calibration overlay; your objects stay. Turn on In margins in the header to place content in the margin bands (wrap labels).

Print calibration — use the Calibrate button (bottom-right): print a test label, drag the yellow box to match real ink limits, then Apply to margins. Pick a tool and click to place; drag to move. With an object selected, drag the blue corner squares (bottom-right = grow; top-left on shapes = shrink/move corner).

Text: SE only — on-canvas size tracks ZPL ^AfN (font f = 0, A–H, P–V) height/width (dots). Barcode: SE only (2D = magnification; QR pattern uses Labelary-compatible encoding when online).

Snap, show grid, and grid spacing are under the canvas. Settings → Layout has default merge tokens for new Text/Barcode tools.

Browsers cannot open raw TCP. Copy PowerShell send and run in PowerShell on a PC that can reach the printer (same site or VPN). With Scan & load applied values, enable “Substitute tokens…” there so [barcode] etc. are replaced in the ZPL before send. Off-site without VPN? Use Flex, or set a Relay URL (POST body = ZPL) on a server that can reach the printer. From a PC, check reachability with: Test-NetConnection <host> -Port <port> (PowerShell).

Config file (JSON): save or load printerHost, printerPort, relayUrl so you don’t retype on each PC. Same folder as the designer is fine.

Flex5 REST is documented in your tenant Swagger UI (use the same host as API base below — yourtenant is a placeholder, not a real subdomain). Create API keys under Integrations → API. OpenAPI expects header X-Auth-Token (not browser login). If the browser blocks the request (CORS), set API relay URL to an HTTPS endpoint you control that forwards the request and returns the JSON body.

USB scanners type into the focused field. Fetch calls the Flex API URL from the Flex API tab (or paste JSON from Swagger “Try it out” / exports). Apply to label fills merge tokens from the JSON using the map below. Then print from the Printer tab (substitution applies when the checkbox is on).
